# Security Policy

## Supported Versions
This website is a static Next.js export. We strive to keep our Node modules and React/Next dependencies up to date. 

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to Stephen Russo at **stephen@russotc.com**. All security vulnerabilities will be promptly addressed.

Please include:
* A description of the vulnerability
* Steps to reproduce the issue
* Any potential impact or risk you've identified

Thank you for helping keep RTC secure.
